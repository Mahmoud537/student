# دفتر — متابعة الطلاب

واجهة عربية لإدارة الفصول والمواد والطلاب، وتسجيل درجات المتابعة الأسبوعية والاختبارين، والحضور والغياب، وإعداد تقرير قابل للطباعة بصيغة PDF.

## التشغيل

```sh
npm install
npm run dev
```

## طريقة الحساب

- الواجب: من 5، كراسة الحصة: من 5، التقييم الأسبوعي: من 10، المواظبة والسلوك: من 5.
- متوسط المجاميع الأسبوعية المسجلة خلال الفصل الدراسي: من 25.
- الاختبار الأول والثاني: كل منهما من 15؛ متوسطهما: من 15.
- إجمالي الفصل: متوسط الأسابيع + متوسط الاختبارين، من 40. لا يُعرض الإجمالي حتى تُسجل متابعة أسبوعية واحدة والاختباران.
- سجل المتابعة مرقم من الأسبوع 1 إلى 19، وتُحسب المتوسطات من الأسابيع التي سُجلت فقط.
- مدة الفصل الدراسي خمسة أشهر من تاريخ بدايته المحدد في لوحة المتابعة.
- يُسجل الغياب اليومي بعذر أو بدون عذر، مع إجمالي شهري وإجمالي للفصل.
- يمكن حفظ اسم المدرسة والإدارة والمديرية لتظهر في تقرير الطالب.

## حفظ البيانات

تُحفظ السجلات في المتصفح والجهاز المستخدمين، ولا يوجد حاليًا حساب مستخدم أو مزامنة سحابية. استخدم تقرير PDF للاحتفاظ بنسخة قابلة للطباعة من سجل الطالب.
